## 已确定的方向

- 项目：中文会议行动助手，从会议文字中发现行动项，经澄清和确认后创建任务。
- 主数据源：ModelScope 的 AliMeeting4MUG；先核验实际可获取的标注与划分。
- 微调目标：从带编号的会议上下文识别行动句；第一阶段不训练端到端万能 Agent。
- 开发环境：Intel Mac 负责数据和应用；按需租用单张 NVIDIA GPU 训练及评估。
- 技术目标：LangChain、LangGraph、工具调用、RAG、Embedding、向量数据库、评估及可观测性。
- 产品范围：文字输入、单场会议、单用户演示、自带任务看板。

## 现在的下一步

先按准备清单获取**少量有行动项标注的会议原始样本**，完成字段、标签和划分审计。审计通过后再构建训练集，不急着租 GPU。

Mac 内存、可接受的租机预算和可用模型 API 尚未确认；这些不阻塞文档与数据审计，进入环境安装、付费训练前再落实。
