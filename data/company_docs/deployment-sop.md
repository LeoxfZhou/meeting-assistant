# Deployment SOP

Synthetic / Fictional Dataset：以下为原创虚构公司“澄川科技”的演示制度，不代表真实公司或法律意见。
版本：1.0；生效日期：2026-11-01。

## 核心规则

发布前备份数据库并核验备份可读，记录当前镜像 digest、迁移版本和回滚命令。启动新容器后检查 health、关键读写接口和错误日志。

## 边界与关联

数据库迁移必须先在 staging 验证，不得执行 docker compose down -v 清空生产卷。若发布后 5 分钟错误率超过 2%，停止扩大流量并由发布负责人决定回滚；破坏性迁移不能假设镜像回滚即可恢复。
